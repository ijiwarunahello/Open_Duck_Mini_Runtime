# bench: モジュール別の動作確認ツール

Pi の上で動かし、PC や Mac のブラウザから各モジュール (GPIO・足スイッチ・IMU・LED・耳・スピーカー・カメラ・サーボ・電池電圧) の生の値を見ながら操作する。組み立て中の不具合を追いかけるための計測器で、合否の判定はしない。

## 起動

Pi で:

```sh
cd ~/Open_Duck_Mini_Runtime
uv run python -m tools.bench.server
```

ブラウザで `http://<Pi の IP>:8000/` を開く (例: `http://172.16.0.33:8000/`)。終了は Ctrl-C。

| 引数 | 内容 |
|---|---|
| `--port 8000` | 待ち受けるポート |
| `--fake` | ハードウェアなしで作り物の値を使う (PC で画面を確かめるとき) |
| `--ear-limit 0.5` | 耳の可動範囲。最大 1.0。画面からは変えられない |

PC で画面だけ試す: `uv run python -m tools.bench.server --fake` → `http://127.0.0.1:8000/`

## 電池電圧

画面上部の「電池」は、サーボ 14 軸の電圧の中央値 (電池専用のセンサーはない)。7.2V 以下で黄、7.0V 以下で赤。サーボが読めないときは「-」。サーボが力を出している間は低めに出る。

## 安全

- 画面右上の「すべて止める」で、全サーボのトルクを切り、LED を消し、耳の PWM を止める。
- 同じ停止処理は、最後のブラウザを閉じたとき (接続が切れたとき)、Ctrl-C や SIGTERM で終了したときにも自動で走る。
- サーボ: トルクを入れられるのは同時に 1 軸だけ (別の軸に入れると前の軸は切れる)。kp は 2 / 8 / 16。1 回 ±0.05 rad、トルクを入れた位置から累計 ±0.3 rad まで。
- LED は点灯から 30 秒で自動的に消える。
- GPIO の汎用操作はプルの切り替え (pu / pd / pn) だけで、出力は出さない。予約 (GPIO0/1/4/14/15) と使用中のピンは変えられない。
- 歩行 Runtime (`v2_rl_walk_mujoco.py` など) が動いているときや、`/dev/ttyACM0` を別のプロセスが開いているときは起動しない。起動中はサーボのポートを排他で開く。

## 開発

```sh
uv run pytest tests/bench
```

`tools/bench/real_hardware.py` は Pi 専用のライブラリを読み込むので、PC のテストでは読み込まない。
